SDET, Software Development Engineer in Test

Remote, United States · Full time · $125,000 to $155,000 USD per year

Own our Java based test framework for web, mobile and backend services, and build the test infrastructure that runs in Jenkins, Docker and AWS.

Interview assessment instructions

  1. Create a separate resume for each of the two jobs. Each resume should be the best possible fit for that one posting.
  2. Match the tools and keywords listed in that specific job. Use the Required tools list and the Requirements as your guide.
  3. Keep the years of experience consistent. Use the same total years on both resumes and in the form.
  4. Do not copy the job description word for word. Write it the way a real resume reads, in your own words.
  5. Use a placeholder candidate name of your choosing, for example Alex Rivera. Any working email address is fine.
  6. Save each resume as a PDF and upload it. After you choose your file you can view it right on the page before you submit.
  7. Apply to both jobs. Job A is the QA Automation Engineer role and Job B is the SDET role.

See both jobs on the assessment page

Responsibilities

  • Build and extend our Java test automation framework with Selenium WebDriver and TestNG
  • Write backend API tests with REST Assured and validate data with SQL queries against PostgreSQL
  • Automate Android and iOS mobile tests with Appium
  • Manage builds and dependencies with Maven and run nightly regression in Jenkins pipelines
  • Run tests in Docker containers and on AWS services such as EC2 and S3
  • Review code from developers and push for testable design and good unit test coverage

Requirements

  • 5 or more years of software testing experience, with at least 3 years writing automation in Java
  • Strong experience with Selenium WebDriver and TestNG
  • Experience testing REST services with REST Assured
  • Hands on Appium experience on Android or iOS
  • Experience with Maven builds and Jenkins pipelines
  • Working knowledge of Docker, AWS and SQL

Nice to have

  • Experience with Selenium Grid or cloud device farms
  • Familiarity with Kafka or other message queues
  • Experience with performance testing in Gatling
  • AWS Cloud Practitioner certification
